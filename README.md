# Thống Nhất Express

A Vietnamese pixel train game built with TypeScript and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The production site is generated in `dist/`. To deploy on Vercel, import this
repository; Vercel should detect Vite and use `npm run build` with `dist` as
the output directory.
